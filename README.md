# Arbitrary-Precision-Calculator-APC-
The Arbitrary Precision Calculator (APC) is a C-based application that performs arithmetic operations on very large numbers beyond the limits of standard data types.  It uses a Doubly Linked List to store each digit dynamically, enabling precise computations without size limitations.

Features
Handles very large integers
Supports:
Addition
Subtraction
Multiplication
Division (Quotient & Remainder)
Supports negative numbers
Efficient carry/borrow handling
Removes leading zeros automatically

Concepts Used
Doubly Linked List
Dynamic Memory Allocation
String Parsing
Big Integer Arithmetic
Data Structures

Working Principle
Each number is stored as a linked list of digits
Operations are performed digit by digit
Result is stored in a new linked list
Output is printed from the result list
